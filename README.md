# The Book Attic

An e-commerce web application built for an online bookstore. The platform provides a complete shopping experience, including user authentication, product catalog filtering, a shopping cart, shipment tracking, and profile management.

## Features

* User Authentication: Secure login and account creation supporting customer and administrator roles.
* Catalog and Filtering: Instant search and category-based filtering across multiple genres.
* Navigation Menu: A responsive side menu for moving between pages.
* Shipment Tracker: Live status tracking for orders across processing, shipping, transit, and delivery stages.
* Account Management: A profile section to view and update personal credentials and delivery addresses.

## Tech Stack

* Frontend: React
* Database: MySQL
* Infrastructure: AWS Application Load Balancer
